# 中国退款政策：有限集成范围

状态：Candidate / 待审核。基线：`809ed796cffaf4a89af730eda5ff81560854ae8d`。

本候选只统一网站和小程序的政策候选提示，将现有退款说明改为可选，并补充相关回归。复用原订单、退款查询、回调与领取权益逻辑；不增加支付产品，不切换真实支付配置，不修改下载入口或安装脚本。

## 与当前代码一致的范围

- 安装完成并有效验收前可申请全额退款；验收后依法享有的售后救济仍保留。
- 付款、下载、安装进程完成均不单独构成有效验收。
- 申请后仍是 `paid/requested/held`，暂停本订单在线领取；只有平台确认成功才成为 `refunded/succeeded/revoked`。确认失败后恢复可用权益。
- 重复退款申请复用退款编号；重复或延迟回调不能恢复已经退款的在线权益。
- 撤销范围是本订单提供的在线权益，不是 Hermes 开源许可或用户文件。有效离线凭证不能承诺实时撤销；当前基线尚不包含该签发和客户端校验链。
- 人工定制独立报价、签约和验收，不套用自助安装或海外条款。

## 未纳入本次集成的依赖

完整政策补丁所依赖的 `apps/payment-server/test_licensing.py`、`scripts/hermes-license.py`、`site/delivery.html`、`site/delivery.js` 在此基线不存在。不得以本候选替代这些依赖的独立审核或运行验收。

当前订单代码也没有可用于有效安装验收的完整证据链。本候选不新增“验收后自动拒绝退款”的判断。验收后法定售后须有经审核的受理渠道、责任人和处理记录；保留提示不代表流程已经运行通过。

发布前仍需：核对实际部署版本；确认商户主体、结算账户、开票资格及现有支付产品适用范围；落实售后处理；完成锁定安装包的中国 Windows/WSL2 与 Mac v0.23.0 独立首次安装验收。Git 无冲突和定向测试通过不代表上述门禁通过。

因本候选改为远端 main 基线，仅运行受影响的 18 项后端和 12 项小程序检查。均为隔离离线测试，没有真实付款、退款或模型调用。新增小程序测试曾因测试脚本路径引用错误失败，修正后单独复测通过；初始记录保留。历史 164 项回归保留在原验收材料中，未重跑，也不冒充本基线的测试覆盖。

本 PR 仅供独立审核，不自动合并、不部署、不开放购买。中国与海外系统保持独立。
