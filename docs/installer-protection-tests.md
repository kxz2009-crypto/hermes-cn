# 实验安装器保护测试

状态：新增测试，结果以对应 CI 运行记录为准。

## 测试项目

1. 已存在的目标目录必须被拒绝。
   比较测试目录内文件内容、权限和目录结构，确认未改变。

2. Intel macOS 的错误 wheel 必须因哈希不符而被拒绝。
   失败后目标安装目录不得存在。
   该项目仅在 Intel macOS runner 执行，其他平台记为不适用。

3. 继承其他 HERMES_HOME 时，hermes-cn --help 必须仍显示
   安装目录内 state/config.yaml。
   测试用旧配置放置无效 YAML，并检查其内容和目录结构未改变。

## 边界

测试在 GitHub runner 的临时目录内执行，不操作用户现有 Hermes。
配置隔离验证只覆盖启动器的 --help 路径，不代表所有子命令、
profile 参数、插件或模型调用都经过隔离验证。
本测试不证明完全断网，也不证明文件系统沙盒隔离。
