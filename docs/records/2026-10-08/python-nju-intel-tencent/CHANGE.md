# Python 南大镜像与 Intel 腾讯云分发

## 修改

- Python 使用南大 python-build-standalone 镜像。
- Python 固定 3.11.17，构建日期固定 20261003。
- 保留 uv 的独立运行时目录和下载校验机制。
- Intel cryptography r2 使用腾讯云上的原始分发包。
- 保留 Intel ZIP、wheel 固定 SHA256 及原有文件提取方式。
- Intel 下载最多三次尝试，总时间预算 300 秒；
  每次覆盖下载文件，避免拼接残缺响应。

  压缩和哈希功能检查通过。

  HTTP 拒绝直接停止；均通过。
