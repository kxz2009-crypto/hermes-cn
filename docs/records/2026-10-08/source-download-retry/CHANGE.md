# 源码下载中断重试修复

## 实际故障

提交 f6e59ce 的 CI 运行 37805021421：
Ubuntu 24.04 / TUNA 在下载腾讯云源码包约 46% 时，
curl 返回 18：连接提前关闭，仍有 41974978 字节未收到。
该运行四组成功、一组失败、一组取消。

另一台电脑使用旧安装器 8a84537，
从 GitHub 获取上游源码时发生 curl 56 连接超时。
这是另一条下载路径，不能据此认定两次故障具有相同原因。

## 修改

- 对指定连接与传输错误最多尝试三次。
- 下载总时间预算 1200 秒，每次请求使用剩余预算。
- 每次尝试重新覆盖下载文件，不拼接残缺响应。
- 持续低于 1024 字节/秒达 60 秒时结束该次请求。
- 完整下载后继续执行原有固定 SHA256 和归档校验。
- HTTP 错误直接停止，当前不自动重试此类响应。

  最终文件只包含第二次的完整内容。

- 返回 22：一次后停止，不进入后续步骤。
