打开 Windows / Mac / Linux 安装指南

新指南使用独立 r3 目录。已有 r2 安装保留，不自动迁移密钥、记忆或会话。

建议安装门槛

  • Windows：Windows 11 x64、4 核 CPU、16 GB 内存，WSL2 + Ubuntu 24.04。
  • Apple Silicon Mac：macOS 15、M1 或更新芯片、16 GB 内存。
  • Intel Mac：macOS 15、4 核 Intel CPU、16 GB 内存。
  • Linux：Ubuntu 24.04 x86_64、4 核 CPU、16 GB 内存。
  • 至少 20 GB 可用 SSD 空间，推荐预留 40 GB；云端模型无需独立显卡。

这是本项目的建议门槛，不是官方最低配置或性能实测结论。Mac 当前仅允许 macOS 15。

多模型配置

GLM Coding Plan、DeepSeek Flash / Pro、Kimi Coding Plan、豆包、Qwen、MiniMax、MiMo、腾讯 HY3 和 Custom。

可配置、选择、查看状态和执行连接检查。豆包模型 ID、MiniMax 接口及模型需按本人控制台填写。

本版统一入口使用 OpenAI Chat Completions 兼容接口。API Key 与套餐需自行准备；check/chat 可能消耗额度。
