一期实验预览

在独立目录安装 Hermes

固定版本、清华源依赖、独立状态目录。从命令行开始体验。

支持范围与验证状态

平台当前证据
Linux x86_64 / WSL2Ubuntu 24.04 CI；WSL 安装及 GLM 简短对话实测
macOS 15 · Apple SiliconPyPI / TUNA 安装及 CLI 启动 CI
macOS 15 · Intelr2 wheel、安装与保护测试；公开分发包自动下载、安装及声明留存专项 CI 通过

Windows 请在 WSL2 内运行。其他 macOS 版本暂不支持。 GitHub runner 测试不等于所有实体设备或国内网络验证。

1. 准备安装工具

需要 Bash、Git、Python 3（含 venv）；Intel 自动下载还需要 curl、unzip 和 shasum。以下命令创建独立 uv 工具环境， 已有目标目录会停止执行。

bash << 'SETUP'
set -euo pipefail
umask 077
tools="$HOME/.local/share/hermes-cn-tools-0.12.23"
[ ! -e "$tools" ] && [ ! -L "$tools" ]
mkdir -p "$(dirname "$tools")"
python3 -m venv "$tools"
(
  unset PYTHONPATH PYTHONHOME
  unset PIP_INDEX_URL PIP_EXTRA_INDEX_URL PIP_FIND_LINKS
  unset PIP_NO_INDEX PIP_TARGET PIP_PREFIX PIP_USER
  export PIP_CONFIG_FILE=/dev/null
  "$tools/bin/python" -m pip install --disable-pip-version-check --no-cache-dir --index-url https://pypi.tuna.tsinghua.edu.cn/simple --only-binary=:all: --no-deps 'uv==0.12.23'
)
"$tools/bin/uv" --version
SETUP

若系统缺少 venv，请先按操作系统文档安装相应组件。 工具自举固定版本，但此步骤尚未采用完整哈希锁定。

2. 获取固定安装器并安装

安装目标必须不存在，路径不能含空白。源码和 Python 下载仍需访问上游服务。

bash << 'INSTALL'
set -euo pipefail
umask 077
adapter="$HOME/.local/share/hermes-cn-adapter-r2"
prefix="$HOME/.local/share/hermes-cn-lite-r2"
commit=a1e57eb0c236a90599d3bc9ba00e28158d7fa0cf
[ ! -e "$adapter" ] && [ ! -L "$adapter" ]
[ ! -e "$prefix" ] && [ ! -L "$prefix" ]
mkdir -p "$(dirname "$adapter")"
git init -q "$adapter"
git -C "$adapter" remote add origin https://github.com/kxz2009-crypto/hermes-cn.git
git -C "$adapter" fetch --depth=1 origin "$commit"
git -C "$adapter" checkout --detach FETCH_HEAD
[ "$(git -C "$adapter" rev-parse HEAD)" = "$commit" ]
bash "$adapter/scripts/install-lite.sh" --prefix "$prefix" --uv "$HOME/.local/share/hermes-cn-tools-0.12.23/bin/uv" --source tuna
INSTALL

完成后运行：

"$HOME/.local/share/hermes-cn-lite-r2/bin/hermes-cn" --help
"$HOME/.local/share/hermes-cn-lite-r2/bin/hermes-cn" --version

Intel 默认下载固定哈希校验的 r2 分发包， 声明及来源保留在安装目录/work/intel-bundle/。 也可通过 --intel-wheel 指定对应本地 wheel，并保留随包声明。

使用前须知

  • 当前提供核心 CLI，模型服务需要自行配置账号和密钥；不要向本站提交密钥。
  • 实测包含国内 GLM Coding Plan 的一次 WSL CLI 简短对话，不代表所有模型和工具可用。
  • 状态文件位于安装目录的 state；目录隔离不等于操作系统沙箱。
  • 不自动安装后台服务、不添加全局 PATH；浏览器及可选组件未纳入验收。
  • 失败时保留现场；暂不支持原地升级或复用失败目录。安装目录不可直接搬迁。
  • 请勿运行 hermes update 改变本实验固定版本。
